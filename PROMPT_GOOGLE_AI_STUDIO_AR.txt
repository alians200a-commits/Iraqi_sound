ابنِ لي تطبيق ويب عربي احترافي باسم «صَوْتَك — Iraqi Voice Studio»، بتصميم داكن فاخر ومتجاوب جداً مع هواتف Android ومتصفح Chrome، ودعم RTL مضبوط.

الهدف: أكتب سكربت باللهجة العراقية، أحدد صوتاً عراقياً، أضغط «توليد»، أسمع التسجيل من مشغّل صوت داخل الصفحة وأحمّل MP3 مباشرة إلى هاتفي.

المطلوب بدقة:
1. استخدم تطبيق Full-stack فعلياً (واجهة ويب + backend Node.js)، وليس HTML ثابتاً أو Web Speech API داخل المتصفح. تجنّب استخدام SpeechSynthesis لأن المطلوب تحميل MP3 حقيقي.
2. في الخادم ثبّت مكتبة npm باسم @andresaya/edge-tts إصدار 1.9.1، واستعمل EdgeTTS.generate(text, voice, options) مع تحويل audio الناتج إلى Buffer وإرجاعه بــ Content-Type: audio/mpeg. المحرك يحتاج اتصالاً بالإنترنت، ويعتمد على خدمة Microsoft، ولا يحتاج Gemini API key.
3. قدّم الصوتين ar-IQ-BasselNeural (باسل، رجالي عراقي) و ar-IQ-RanaNeural (رنا، نسائي عراقي)، مع اختيار واضح؛ واضبط سرعة الكلام من 0.70x إلى 1.30x، والنبرة من -30 إلى +30Hz.
4. استخدم endpoint في الخادم POST /api/generate يقبل {text,voice,speed,pitch} فقط، ويتحقق من النص والخيارات، ويعيد مباشرة ملف MP3 دون كتابة الملفات للقرص أو حفظ السكربت بالخادم.
5. بالواجهة استخدم fetch لطلب /api/generate، ثم response.blob() و URL.createObjectURL(blob) لتشغيل الصوت عبر عنصر audio وإنشاء رابط Download يعمل على Android؛ وأظهر حالات تحميل وأخطاء مفهومة باللهجة العراقية.
6. أضف زر مثال لسكربت عراقي، زر نسخ ومسح، عداد حروف، وحفظ مسودة النص على جهاز المستخدم عبر localStorage فقط، مع تصميم لمس ممتاز وشاشة هاتف ضيقة.
7. لا تعرض أي زر بشكل وهمي؛ لازم كل زر يؤدي وظيفة. ولا تستخدم CDN API مجهولاً، ولا تضع مفاتيح API داخل الواجهة.
8. حد أمان لكل مقطع 4500 حرف، وقيد وصول بسيط لمنع إساءة استخدام خادم منشور للعموم. أوضح للمستخدم أن الخدمة الخارجية قد تفرض قيوداً وأن مجانية النطق غير مضمونة دون سقف.
9. شغّل الخادم على 0.0.0.0 والمنفذ process.env.PORT أو 8080 حتى يناسب Cloud Run، وأضف /api/status لفحص الاتصال بالخادم.
10. اجعل كود التطبيق قابلاً للنشر عبر Publish في Google AI Studio إذا كان الحساب مؤهلاً، مع إبقاء كل وظائف توليد وتحميل MP3 في التطبيق المنشور لا مجرد واجهة معاينة.

إن وجدت ملفات مستوردة من GitHub لمشروع Sawtak v3، حافظ على الواجهة الحالية والبنية البرمجية وعدّل فقط ما يلزم لمواءمتها مع Google AI Studio. اختبر تشغيل الخادم واختبر أن endpoint يرسل audio/mpeg فعلاً قبل إعلان نجاحه. لا تحول المشروع إلى Gemini TTS إلا إذا طلبت ذلك لاحقاً.
