عندي تطبيق صَوْتَك v4 مستورد من GitHub. أصلح routing في Preview بحيث يصل POST /api/generate وGET /api/status إلى server.mjs الذي يبدأ بـ npm start على process.env.PORT. لا تستخدم mock ولا صفحة HTML كاستجابة API. تأكد أن GET /api/status يعيد JSON فيه app=sawtak وversion=4.0.0، ثم افحص رد POST من محرك Edge: Content-Type audio/mpeg وملف MP3 يبدأ ID3 أو MPEG frame. عند الفشل أعرض رسالة الشبكة أو السجل الحقيقي، ولا تعرض نجاحاً وهمياً. تم دمج خيار Habibi-TTS Specialized/IRQ في الواجهة والخادم، لكنه يحتاج خدمة Python منفصلة (habibi_service/) وHABIBI_URL وHABIBI_API_KEY كمتغيرات سرية على الخادم. لا تزعم تشغيل Habibi في Preview بلا تلك الخدمة. إذا كان Preview لا يشغّل هذا الخادم Node، جهز Dockerfile للنشر على Cloud Run وأوضح الخطوة التي تحتاجها مني.
