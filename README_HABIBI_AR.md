# صَوْتَك v5 — السكربتات العراقية الطويلة

الإضافة **تحافظ على محرك Edge-TTS الحالي** كما هو، وتضيف قسم Habibi-TTS المستقل أسفل الصفحة.

## الوظائف
- تقسيم النص الطويل آلياً إلى مقاطع عراقية بنحو 65–170 حرفاً (مع مراعاة نهاية الجملة بقدر الإمكان).
- توليد كل مقطع من نموذج `SWivid/Habibi-TTS`, `Specialized/IRQ` الحقيقي عند ربط خادم النموذج.
- الاستماع إلى المقاطع منفردة وإعادة توليد أي مقطع فقط.
- دمجها داخل Chrome/Android إلى **WAV** واحد قابل للتنزيل، بدون رفع المقاطع لخدمة دمج ثانية. صيغة MP3 متاحة للمقاطع المنفردة فقط عندما يتوفر ffmpeg بخادم Python؛ لا ندّعي MP3 للملف المجمّع.
- إظهار أن Habibi غير مربوط (بدلاً من زر يدّعي عمله) حتى تُضبط إعدادات الخادم.

## نشر خادم Habibi
خادم `Node.js` الحالي وحده لا يحوي نموذج Habibi. يلزم مضيف Python منفصل بموارد حوسبة كافية وأوزان النموذج (~1.35GB قبل المكتبات). يمكن تشغيل `habibi_service/server.py` وفق `habibi_service/README.md`، ثم ضبط متغيرين **على خادم Node فقط**:

```
HABIBI_URL=https://YOUR_PYTHON_WORKER_HOST
HABIBI_API_KEY=A_RANDOM_SECRET_SHARED_WITH_WORKER
```

إذا لم يتوفر مضيف Python، جرّب تقسيم النص من الصفحة؛ التوليد سيبقى معطلاً وهذا متوقع. Google AI Studio Build وحده لا يشغّل النموذج الكبير تلقائياً، ولا يوجد ضمان لاستضافة GPU مجانية بلا حدود.

## تحقق ما بعد التحديث
1. افتح الصفحة المنشورة من Chrome؛ مرّر إلى قسم **Habibi — السكربت الطويل**.
2. اكتب نصاً طويلاً في حقل السكربت بالأعلى، واضغط **تقسيم السكربت تلقائياً**.
3. لتوليد الصوت فعلياً، شغّل خادم Python واربط المتغيرين السريين (لا تضعهما داخل GitHub).
4. اضغط **توليد المقاطع العراقية**؛ بعد نجاحها استمع لكل مقطع، وأعد توليد غير المرضي، ثم **دمج المقاطع وتحميل WAV**.

## حدود هذه النسخة
- التقطيع واختبارات واجهة الخادم فُحصت محلياً؛ لم نجرِ اختباراً حقيقياً للتوليد بأوزان Habibi على GPU.
- الخادم الحالي يشغّل أمر CLI منفصلاً لكل مقطع، ويحمل النموذج من جديد كل مرة؛ هذه نسخة تجريبية وظيفية وليست محسّنة للسرعة أو الأحمال الكبيرة.
- النسخة تحافظ على سكربتات Edge الموجودة في المستودع، وتضيف API مستقلة إلى `/api/habibi/*`.
