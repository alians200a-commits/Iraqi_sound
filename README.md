# صَوْتَك | Iraqi Voice Studio

تطبيق ويب لتحويل النص إلى صوت عراقي (باسل أو رنا) وحفظ MP3، بواجهة عربية متجاوبة مع الهاتف.

- المحرك: Edge TTS عبر خادم Node.js.
- التشغيل: `npm install` ثم `npm start` (يتطلب Node.js 20 أو أحدث).
- افتح `http://localhost:8080` أو انشره على خادم يدعم Node.js.
- يمكن استيراد المشروع إلى Google AI Studio Build من GitHub.

**ملاحظة:** توليد الصوت يستخدم خدمة Microsoft عبر الإنترنت؛ مجانية الاستخدام أو عدم وجود حدود غير مضمونين، ويجب اختبار التوليد على بيئة النشر. لا يكفي GitHub Pages لتشغيل الواجهة وحدها لأن التوليد يحتاج خادماً.

راجع `README_AR.md` لتعليمات التشغيل والنشر بالتفصيل.
