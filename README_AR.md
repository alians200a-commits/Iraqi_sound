# دليل التشغيل — صَوْتَك v6

هذه النسخة تركّز على الأصوات العراقية من Sawtak Arabi فقط. أزلنا التكامل مع باسل ورنا وHabibi ومكتباتهما، مع الإبقاء على واجهة الهاتف.

## Google AI Studio
1. حدّث مشروع صَوْتَك من GitHub، واختر نسخة GitHub عند تعارض الملفات التي لم تعدّلها بنفسك.
2. تحقق من وجود أسرار الخادم `SAWTAK_API_KEY` و`SAWTAK_APP_PASSWORD` (12 حرفاً أو أكثر). **لا تشارك القيم ولا تنسخها داخل Chat.**
3. افتح Preview، واكتب رمز الدخول فقط، ثم اضغط «جلب الأصوات العراقية».
4. اختار صوتاً، واكتب السكربت، وحدد سرعة 0.90× كبداية.
5. اضغط توليد، وبعدها اضغط التأكيد مرة ثانية (قد يستهلك من رصيد الحساب).
6. اختبر الصوت وحمّل WAV. زر «تحديث الرصيد» يقرأ الأرقام الفعلية من حسابك.

## معرفة استهلاكك
- الرصيد المتبقي: من `GET /me`، بالدولار الأمريكي.
- استهلاك آخر 30 يوماً و730 يوماً: مجموع سجلات `GET /usage`، وقد يتأخر حتى ساعة.
- الحروف المتبقية: تقدير حسب 0.05$ لكل 1000 حرف، وليس حصّة رسمية من المزوّد.
- إذا تغيرت أسعار Sawtak Arabi، يكون تقدير الحروف فقط غير دقيق؛ يعتمد الرصيد الفعلي على `GET /me`.

## السرعة
الواجهة تضبط سرعة التوليد بعد رجوع WAV باستخدام FFmpeg `atempo` للمحافظة على طبقة الصوت. مكتبات Sawtak لا توفر حقل سرعة رسمي ضمن طلب التوليد. Dockerfile يشمل FFmpeg، لكن معاينة Google AI Studio قد لا تحتوي FFmpeg؛ إذا تعذر التبطيء تظهر رسالة واضحة: المشغل أبطأ داخل المتصفح فقط والملف الأصلي لم يتغير. **لا يُدفع مرة أخرى بسبب تعديل السرعة.**

## تشغيل عبر Docker
`docker build -t sawtak-iraqi .`

`docker run --rm -p 8080:8080 -e SAWTAK_API_KEY -e SAWTAK_APP_PASSWORD sawtak-iraqi`

يتطلب هذا تعريف الأسرار في بيئة التشغيل؛ لا تضفها للأوامر العامة أو لملفات GitHub. لا تشارك رابط التطبيق على العموم إذا رمز الدخول مكشوف. واجهة رمز الدخول ليست بديلاً عن تسجيل دخول مستخدم منفصل لكل شخص.

ملاحظة: فحص الكود لا يؤكد نجاح التوليد على الاستضافة؛ اختبر ملفاً قصيراً بعد مزامنة المشروع.
