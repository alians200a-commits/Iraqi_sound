# صَوْتَك v3 — ويب وموبايل بلا Termux

هذا مشروع حقيقي يحوي واجهة ويب عربية وخادماً بـ Node.js لتوليد MP3 بصوتين عراقيين من خدمة Edge TTS عبر مكتبة `@andresaya/edge-tts` (v1.9.1). يمكن تشغيله على خادم Node أو تطوير نسخة منه عبر Google AI Studio Build.

## أسهل طريق من الموبايل فقط: Google AI Studio

1. افتح https://aistudio.google.com/ من Chrome وسجل بحساب Google.
2. ادخل **Build** واختر **Web app**.
3. افتح ملف `PROMPT_GOOGLE_AI_STUDIO_AR.txt` وانسخ النص كله إلى حقل الطلب في Build، ثم أرسل الطلب.
4. افحص المعاينة: هل الصوت يولّد MP3 وينزل ملفاً فعلياً؟ لا تكتفِ بظهور الواجهة.
5. اضغط **Publish** إذا كان الخيار متاحاً لحسابك. قد يتاح Starter Tier لحسابات مؤهلة فقط، أو يتطلب Cloud billing وفق حالة الحساب.
6. بعد النشر افتح رابط التطبيق على الموبايل. في Chrome اختر قائمة ⋮ ثم «إضافة إلى الشاشة الرئيسية» لفتحها كتطبيق ويب دون تنزيل APK.

> هذه الطريقة تنشئ تطبيقاً من الوصف وتسمح بتعديله بالمحادثة، لكنها ليست استيراداً حرفياً لهذه الملفات.

## استيراد الكود نفسه عبر GitHub إلى AI Studio

1. من الهاتف افتح https://github.com/new وأنشئ مستودعاً جديداً باسم `sawtak-iraqi-tts`.
2. فك ضغط ZIP من تطبيق الملفات الموجود في الهاتف، وارفع ملفات المشروع وفولدر `public` إلى المستودع (المستودع يحتوي الجذر: `package.json`, `server.mjs`, `public/`...). لا ترفع ملف ZIP وحده وتنتظر تشغيله.
3. افتح Google AI Studio > Build > علامة إضافة الملفات (+) > **Import from GitHub** وحدد المستودع.
4. انسخ الأمر الموجود بملف `PROMPT_GOOGLE_AI_STUDIO_AR.txt` أو اطلب منه الحفاظ على الكود الأصلي وتكييفه لبيئة Build.
5. تحقّق من توليد ملف MP3 فعلي، ثم انشر التطبيق عند توفر الخيار المناسب.

**تنبيه**: الاستيراد من GitHub ميزة موثقة رسمياً، أما رفع ZIP مباشرة إلى Google AI Studio فقد لا يكون مدعوماً كاستيراد مشروع قابل للتشغيل. لهذا نوصي بخيار Build من الـ prompt أو Import from GitHub.

## تشغيله على أي خدمة Node.js/Cloud Run

- Node 20 أو أحدث.
- `npm install`
- `npm start`
- افتح `http://localhost:8080`.
- في الاستضافة العامة، استخدم HTTPS وفعّل المصادقة وإعدادات الأمان إن كان التطبيق للاستخدام الشخصي فقط.

## حقائق مهمة

- **لا يحتاج تنزيل برامج على الهاتف** حين يكون منشوراً على خادم سحابي.
- **لا يحتاج Gemini API key** في النسخة الحالية: يعتمد على خدمة Microsoft Edge الصوتية غير الرسمية؛ قد تتوقف أو تغير حدود الاستخدام دون إنذار.
- **ليس غير محدوداً على نحو مضمون**: واجهتنا لا تفرض رصيداً، لكن هناك 4500 حرف كحد للمقطع و8 طلبات/دقيقة للحماية. الاستضافة ومزوّد الصوت قد يقيّدان التشغيل.
- **Habibi المحلي ليس مدمجاً في هذه النسخة السحابية** لأن النموذج قد يحتاج موارد وتشغيلاً أثقل. النسخة هنا Edge فقط لتكون خفيفة.
- النص يُرسل إلى خدمة الصوت الخارجية، فلا تستخدمه للبيانات الحساسة.
- التسجيل الصوتي الناتج لا يُحفَظ على الخادم. يتم إرساله مباشرة إلى المتصفح للتحميل.
- المشروع مفتوح للتعديل وليس خدمة مستضافة حالياً. تشغيل الصوت يعتمد على توفر الخدمة الخارجية في بيئة النشر؛ يلزم اختبار عملي بعد النشر.

## الملفات

- `server.mjs`: خادم Node.js ونقطة نهاية MP3.
- `public/index.html`, `style.css`, `app.js`: الواجهة المتجاوبة.
- `public/manifest.webmanifest`, `icons/`: إضافة الصفحة إلى الشاشة الرئيسية.
- `package.json`: تبعيات Node.
- `Dockerfile`: مسار نشر Docker عام.
- `PROMPT_GOOGLE_AI_STUDIO_AR.txt`: أمر جاهز يُنسخ إلى Google AI Studio Build.
